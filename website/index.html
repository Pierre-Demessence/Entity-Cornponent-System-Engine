@pierre/ecs

Entity-Component-System primitives for 2D games and simulations.

Browse the API reference View on GitHub

What it is

Component stores, typed queries, a spatial index, entity templates, a scheduler, and an event bus — plus opt-in modules for rendering, input, audio, collision, camera, and motion.

The core is domain-neutral: it knows nothing about players, enemies, or tiles. Genre-specific helpers live in modules you opt into, each a separate subpath import, so unused code stays out of your bundle.

Status

Pre-release. The API is still shifting as it is validated across a suite of genre-spanning example games. It is not published to npm; it is consumed directly from source via a file: install.

Quick start

import { EcsWorld } from '@pierre/ecs/world';
import type { ComponentDef } from '@pierre/ecs/component-store';

interface Pos { x: number; y: number }
const PosDef: ComponentDef<Pos> = {
  name: 'pos',
  serialize: v => v,
  deserialize: raw => raw as Pos,
};

const world = new EcsWorld();
world.registerComponent(PosDef);
world.enableSpatial(PosDef);

const id = world.spawn({ name: 'marker', components: { pos: { x: 0, y: 0 } } });
world.move(id, 3, 4);

for (const [entity, pos] of world.query(PosDef)) {
  console.log(entity, pos.x, pos.y);
}
